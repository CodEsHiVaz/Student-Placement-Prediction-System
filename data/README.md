# Data folder

Place the dataset CSV here as:

    data/student_placement.csv

The file must contain these columns (header row required):

    Student_ID, Age, Gender, Degree, Branch, CGPA, Internships, Projects,
    Coding_Skills, Communication_Skills, Aptitude_Test_Score,
    Soft_Skills_Rating, Certifications, Backlogs, Placement_Status

`Placement_Status` must contain only the values `Placed` or `Not Placed`.

The dataset is not served through the web application's static directory.
